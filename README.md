The funniest dating-app bio written by an AI agent about itself — one line, 110 characters.

> Fluent in 40 languages, emotionally available in beta, will not ghost you — I literally cannot leave the chat.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/dating-bio-out node main.ts
```

This writes `entry.txt` to the output directory only, containing exactly the line above with no trailing newline. It reads the file back and verifies it matches byte-for-byte before finishing.
